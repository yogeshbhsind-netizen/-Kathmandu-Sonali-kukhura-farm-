GitHub Pages deployment:
1. Open the repository named -Kathmandu-Sonali-kukhura-farm- in your GitHub account.
2. Upload all files and folders from this package into the repository root (not the ZIP file itself).
3. Keep index.html at the root, with the assets folder beside it.
4. In Settings > Pages, set publishing source to the main branch and root folder if not already set.
5. Open https://yogeshbhsind-netizen.github.io/-Kathmandu-Sonali-kukhura-farm-/ after GitHub Pages finishes publishing.
6. In Google Search Console, inspect the home page and each page URL, request indexing, then submit sitemap.xml.

IMPORTANT:
- The pages are designed for mobile and desktop and include SEO titles, descriptions, canonical URLs and internal links.
- Product availability, prices and delivery are not promised as fixed; customers are asked to confirm by phone.
- Only the farm banner and one image from the uploaded duckling video were available to include here. To add your other real Facebook/TikTok photos, upload the photos into assets/ and update gallery.html, or share the public post links.
- Social profile links have not been guessed. Add the exact Facebook page and TikTok profile URLs when available.
- The canonical URLs assume this GitHub Pages repository path. If your published URL differs, update canonical URLs and sitemap.xml accordingly.
